# Pokemon Explorer

## Description
Pokemon Explorer is a React application that allows users to search for Pokémon using the PokéAPI. Users can view Pokémon information, save favorites, and keep favorites even after refreshing the page.

## Technologies Used

- React
- Vite
- Context API
- Fetch API
- CSS
- localStorage
- PokéAPI

## Features

- Search Pokémon
- View Pokémon image
- View Pokémon type
- View height and weight
- Loading indicator
- Error handling
- Favorites
- Remove favorites
- localStorage persistence

## Future Improvements

- More Pokémon statistics
- Better animations
- Filter Pokémon by type
